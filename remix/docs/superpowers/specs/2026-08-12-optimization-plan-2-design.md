# 优化计划二：设计优化（视觉效果）

> 目标版本：v0.2.0 系列第二步。失败则回退至 v0.1.x 并记录原因。

## 背景与问题

当前 UI 为功能优先的深色主题：波形纯青色 `#22d3ee`、网格白线、序列卡片朴素列表。缺少：
- 视觉层次（卡片阴影/层级、重点元素高亮）
- 波形美学（渐变、峰值立体感）
- 状态反馈（hover/active、播放中高亮）
- 响应式细节（窄窗口下控制栏换行、滚动条样式）

设计方向：**保持深色「节奏工作台」气质，增强对比与层级，不引入外部资源**（零外部请求约束）。

## 方案设计

### A. 主题体系

- **A1. 颜色系统**：从单一青色扩展为「青主色 + 玫红强调 + 金黄标记」的语义色板，`THEME` 常量集中管理（render.js 已有 THEME，扩展字段）：
  - 背景分层：`#0a0c10`（页面）→ `#0e1014`（波形区）→ `#12151b`（网格区）→ 卡片 `#161a22`。
  - 波形渐变：峰值线用 `createLinearGradient`（青 → 青蓝），选区填充半透明青。
  - 播放线玫红加发光（`shadowBlur`），标记金黄。
- **A2. 波形渲染美化**（render.js draw）：
  - 峰值线改为渐变笔触 + 轻微 `shadowColor` 青色光晕；
  - 选区高亮改为「填充 + 上缘亮线」；
  - 时间轴刻度圆点化/更清晰（当前 `fmtTime` 纯文本）。
- **A3. 组件样式**（index.html `<style>` + ui.js 卡片）：
  - 序列卡片：圆角 10px、边框 `rgba(255,255,255,0.06)`、hover 抬升（`translateY(-1px)` + 阴影）、拖拽中高亮边框；
  - 控制栏按钮：统一高度、hover 背景、active 按压效果、播放/暂停主按钮青色渐变；
  - 输入框（unitInput 小/格、BPM 输入）：聚焦边框青色发光；
  - 滚动条：WebKit 自定义细滚动条（深底浅拇指）。
- **A4. 播放态反馈**：
  - 播放中：波形区上缘一条 2px 青色进度扫过（叠加层已有播放线，补充进度条）——**注意：性能计划已隔离播放线层，进度条复用同一叠加层**；
  - 序列卡片正在播放的段落：卡片左侧 3px 玫红竖条（`renderSequenceList` 传入 playingId）。
- **A5. 布局微调**：
  - 控制栏与状态栏间距、字体大小统一（`--font-mono` 时间数字）；
  - 空状态提示（未导入文件时波形区中央灰字提示）。

### B. 不改变

- 交互逻辑（interact.js 手势、modal.js 流程、ui.js 拖拽排序逻辑）只改样式类名/结构不变量；
- 不新增外部字体/图标库（保持零外部请求）。
