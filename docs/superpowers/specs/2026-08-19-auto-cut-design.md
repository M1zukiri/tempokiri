# 设计：自动剪辑（无痕剪切点检测 + 方案导入）

> 目标版本：v1.8.0（核心）→ v1.9.0（增强）。
> 状态：已实施并验证（145/145 单测全绿、无头 Edge 冒烟 SMOKE OK；见 CLAUDE.md 版本历史）。

## 背景与问题

工作站原有工作流：用户手动双击小节选段 → 添加序列 → 拼接试听 → 导出。对一首 3 分钟的歌曲，手动挑选剪切点耗时且依赖听感经验；剪切位置选得不好（切断音符/瞬态、落在能量高处），拼接处会产生咔嗒声或节奏断裂。

目标：**自动识别可"无痕剪辑"的位置**（剪切点），给出分段方案，一键导入拼接序列。无痕拼接的条件与人工经验一致——剪切处信号连续、能量低谷、节奏对齐。

## 无痕剪切定义（三条件）

1. **能量低谷**：剪切点位于乐句间隙/呼吸处，避免切断音符与瞬态；
2. **信号连续**：剪切点处波形幅度小、斜率小（过零附近），拼接瞬间无幅度跳变；
3. **节奏对齐**：存在节拍网格时，剪切点优先对齐网格线（小节线 > 拍线，半径 120ms），节奏连贯。

## 算法设计（src/autoCut.js，纯函数，UMD）

```
pcm(22050) → energyEnvelope（积分图 O(n) RMS 包络）
           → findValleys（平台 span 极小值 + 两侧峰谷深，5% 显著性阈值滤伪谷）
           → valleyCenter（谷底平台中心：静音段取区间中央而非边缘）
           → locateCutPoint（谷内最小差分定位：|Δx| + 0.5|x| + 中心偏置）
           → gridAlign（可选：小节线优先，其次拍线，半径 120ms）
           → scoreCut（三因子加权 0-100）
           → buildPlan（范围过滤 + 过短段循环合并 → 分段方案）
```

| 步骤 | 要点 |
|---|---|
| energyEnvelope | `win=1024, hop=256`（≈46ms/11.6ms）；平方和积分图，每窗 O(1) |
| findValleys | 局部极小（含平台）；谷深 = min(左右峰) - 谷值，平台 span 外扩 5 点取峰；谷深 < 全局最大值 5% 的丢弃（正弦持续段的微波动不致伪谷）；相邻平台合并 |
| locateCutPoint | 搜索半径 win×0.75；成本 = `|pcm[i+1]-pcm[i]| + 0.5·|pcm[i]| + 1e-4·|i-center|`（最后一项使静音平台取中心） |
| gridAlign | 网格吸附半径 120ms；小节线优先于拍线（bars 先于 beatTimes 匹配） |
| scoreCut | 能量分 50·depth/maxDepth + 连续分 30/(1+cost·8) + 网格分 +20（bar/beat），clamp [1,100] |
| buildPlan | 相邻剪切点间隔默认 = 最小段长（防碎切）；过短段循环合并（删除使任一段 < minSegSec 的剪切点）；无保留剪切点返回空方案 |

**参数**：`minSegSec`（最少段长，默认 3s）、`alignGrid`（对齐开关=是否传 grid）、`minGapSec`（默认取 minSegSec）、`maxCuts=14`、`searchStart/searchEnd`（分析范围，默认全曲/网格覆盖区）。

**评分设计意图**：原 v1.8.0 评分仅 `20+80·depth/maxDepth`（谷深归一化），两个同深谷无法区分；v1.9.0 改为三因子加权，连续度与网格对齐参与评分，展示更贴合"无痕质量"，且 scoreCut 为纯函数便于单测调参。

## 前端设计（src/autoCutModal.js + main.js 接线）

- 工具栏「✂ 自动剪辑」（btnAutoCut）→ `runAutoCut`：视频未提取音轨时先采集 → `analyzeAutoCutPlan`（同步分析）→ 打开方案弹窗。
- 弹窗内容：
  - 标题/副标题 + 分析范围行（网格覆盖范围 or 全曲）；
  - **参数行（v1.9.0）**：最少段长 2s/3s/5s + 「对齐网格」开关（无网格时隐藏）；变更即时调 `onAnalyze` 重算并更新（无需确认按钮）；
  - **摘要行（v1.9.0）**：拼接总时长 + 保留原音频百分比；
  - 剪切点表：位置 / 小节（timeToBarCell）/ 依据（对齐小节线｜对齐拍线｜能量低谷）/ 质量分（0-100 分级着色）/「▶ 试听」（前后 2s）；
  - 分段方案表：# / 时间范围 / 时长 /「▶ 试听」（整段）；
  - 一键导入（替换现有序列前弹确认）/ 取消。
- 试听：`previewAutoCutRange(start, end)` 播放原曲区间（音频/视频路径复用，先停旧播放，状态栏"试听中"），复用 `playAudioSegment`/`playVideoSegment`。
- 波形标记：剪切点橙色实线 + 顶部菱形（三主题 `cutLine` 色），弹窗取消/关闭/导入时清除（`state.cutPoints`）。
- 导入：序列项 `startBar/endBar=null`（时间为主，与手动添加一致），经 `saveWorkspace` 持久化；有网格时范围限定在网格覆盖区保证 `timeToBarCell` 有效（anyInvalid 不误判）。

## 验收标准

- 单测 145/145 全绿、`python build.py` 无文案缺失/冗余警告；
- 无头 Edge 冒烟 SMOKE OK；
- 交互符合项目确认制：导入前替换需确认、取消/关闭清除剪切点标记；
- 已知边界：普通曲目（无长停顿）剪切点过密时被最小段长约束过滤，弹窗提示"未找到合适的剪辑位置"（属预期行为，非缺陷）。
